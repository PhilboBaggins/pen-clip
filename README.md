# Clip

A clip to hold 3 cartridge shaped pens.

![Photo of clip with 3 pens in it](photo-1.jpg)
![Photo of clip with 3 pens in it](photo-2.jpg)

This project was designed in [Blender](https://www.blender.org/).
`clip.blend` is the Blender source file and `clip.stl` is exported from Blender for 3D printing.
